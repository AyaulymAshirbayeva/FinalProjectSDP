# Factory Method и Decorator

Реализация использует существующие `Word` и `LessonProduct`. Код Builder,
Strategy, Observer, Facade и Main не изменён. Здесь нет нового меню, хранения
данных или управления учебной сессией.

## Factory Method

- `CreatorAbstract.createExercise(Word, List<Word>)` — фабричный метод.
- `MultipleChoiceCreator` создаёт `MultipleChoiceExercise`.
- `FillBlankCreator` создаёт `FillBlankExercise`.
- Общий метод `createExercises(LessonProduct)` вызывает фабричный метод для
  каждого слова урока. Он не выбирает тип через switch и не зависит от
  конкретного продукта.

Все продукты реализуют `factory.products.ExerciseInterface`:

| Метод | Назначение |
|---|---|
| `getWord()` | Исходный Word, включая данные для планировщика повторения |
| `getPrompt()` | Текст задания без чтения или печати в консоль |
| `getOptions()` | Неизменяемые варианты ответа; пустой список у FillBlank |
| `checkAnswer(String)` | Проверка ответа без изменения прогресса |

MultipleChoice предлагает от двух до четырёх вариантов из словаря урока.
Правильный ответ всегда присутствует; порядок перемешивается. Дистракторы
берутся из того же языка, без повторений и без слов с тем же переводом.
Если подходящего дистрактора нет, создание завершается
`IllegalArgumentException`: следует добавить слова или выбрать FillBlank.
Конструктор с `Random` позволяет воспроизводимо проверять перемешивание.

Ответ MultipleChoice — номер варианта, начиная с 1, либо сам термин.
Строки из цифр всегда трактуются как номера; числовой термин тоже выбирается
по номеру его варианта. Неверный номер, пустой ответ и null дают false.

FillBlank использует `Word.exampleSentence` с ровно одним маркером `___`;
ответом служит `Word.term`. Регистр и внешние пробелы не учитываются.
Unicode приводится к NFC, но акценты сохраняются: café и cafe — разные ответы.
Правила проверки не зависят от локали системы.

## Decorator

`DecoratorAbstract` реализует тот же `ExerciseInterface` и хранит внутри
другое упражнение. `HintDecorator` добавляет `Word.hint` к тексту,
`TranslationDecorator` — `Word.translation`. Можно оборачивать оба типа
упражнений и сочетать декораторы в любом порядке.

Декораторы делегируют проверку ответа, варианты и исходный Word.
Они не изменяют базовое упражнение, оценку или порядок вариантов.
Подсказка должна быть непустой, если включён HintDecorator.
TranslationDecorator особенно полезен для FillBlank; в MultipleChoice
перевод уже является частью основного вопроса.

Пустые дублирующие заготовки из `decorator.components` удалены.
Для фабрик и декораторов используется один импорт:
`LanguageLearningApp.factory.products.ExerciseInterface`.

## Подключение

Код сессии выбирает `CreatorAbstract`, вызывает `createExercises(lesson)`,
при необходимости оборачивает полученные упражнения декораторами и передаёт
ответ в `checkAnswer`. На основании результата вызывающая сторона обновляет
прогресс и публикует события. Паттерны не делают этого самостоятельно.

Новый формат задания добавляется отдельным продуктом и наследником
`CreatorAbstract`. Существующие декораторы продолжат работать, если продукт
соблюдает `ExerciseInterface`.

## Проверка

Нужен JDK 17 или новее. Из корня репозитория в PowerShell:

```powershell
.\scripts\project.ps1 test
```

Скрипт использует JAVA_HOME или java/javac из PATH.
Если JDK не добавлен в окружение, передайте путь через `-JdkHome`.
Для компиляции без тестов используйте задачу `build`.
Сторонние библиотеки и загрузка зависимостей не нужны.

`FactoryTest` проверяет продукты, работу с уроками Builder, варианты ответа,
валидацию и Unicode. `DecoratorTest` проверяет композицию обоих декораторов
на обоих продуктах, неизменность исходного задания и делегирование проверки
произвольному продукту. Проверки выбрасывают AssertionError независимо от
флага JVM `-ea`.
